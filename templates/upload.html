Format 1 Requirements

The uploaded file must be a .csv file and must include:

  • Exactly one .csv file
  • tableName
  • seriesName
  • label
  • One or more yearly data columns such as 2018 to 2050

Only these columns are allowed in this format. Rows cannot contain empty values. If a required column is missing, a year column is missing, a cell is empty, or a yearly value is not numeric, the user will receive a specific error message.

Format 2 Requirements

Choose one or more dashboard tables, then upload the unique source .csv files they require.

  • One or more selected tables
  • The unique source .csv files shown below
  • Scenario, Period, and Pv columns
  • The table-specific dimensions required by the selected table definition

Each scenario found in the file will be uploaded separately. Existing scenarios are allowed. If any selected table already has data for a scenario, the admin can choose to overwrite those selected tables.
